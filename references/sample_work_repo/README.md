# 仕事管理リポジトリ（サンプル）

contextflow と併せて使う Git リポジトリの構成サンプル。
`config.toml` の `[paths] context_repo` にこのフォルダを指定すると、そのまま読み書きできる。

## 現在地

- サンプル案件の連携方式を検討中
- 法務レビューの回答待ちが1件

## 管理方針

- コミットで作業履歴を記録し、「何をしたか」「なぜ変更したか」をファイルに残す
- ブランチに検討過程、`main` ブランチに検討結果を記録する
- 各 `README.md` で現在地を管理する
- **具体的な実施日時はここでは管理しない**（カレンダー側で管理する）

## contextflow との関係

| ファイル | contextflow の扱い |
| --- | --- |
| `10_projects/*/tasks.md` | **読み取りのみ。** 書き換えない（Issue 同期の正本のため） |
| `10_projects/*/decisions.md` | **変化・判断を追記する。** 既存行は消さない |
| `20_knowledge/90_daily_activity/` | 日次サマリの出力先（既定では書き出さない） |
| `99_old/` | 案件走査から除外 |
